VisorOS for Plasma

Halo Infinite's VISR OS isn't really a helmet overlay. It's one operating system that runs on every UNSC device: the menus, the HUD, the ammo display on the gun, the Warthog dashboard, terminals. This concept treats your desktop as one more device running it. It follows the rule 343 described: front-end systems are flat, muted, cool and "lighter", and back-end systems are neon green, "Windows" versus "DOS".

Accessibility rule carried over from 343: state is never shown by color alone. "Selected" is a fill change, "warning" gets a ▲ shape, and text size scales everywhere from one setting (Plasma's global font size).

02Your four screens

These are drawn to your monitors' real physical sizes, with the right 1440p screen as primary and the 1080p landscape screen above it. The UI is drawn at about 3× scale so you can read it. Every screen gets its own top taskbar showing only that screen's apps. Each bar is a separate panel, so you can move any one of them to the bottom or a side on its own.

05Build plan

A Plasma "look" is really about ten separate theme types, each in its own folder and format. The plan builds them in order of payoff and bundles everything into one Global Theme at the end. The front-end/back-end split runs through all of it: two color sets, one set of shapes.

0SETUP

Toolchain, backup, primary screen

  • Repo at ~/claude_shit/visoros-kde/, one folder per layer, plus an install.sh that symlinks into ~/.local/share so edits show up live.
  • Install kvantum, plasma-sdk (plasmoidviewer, plasmathemeexplorer), inkscape, konsave, and the fonts (Saira Semi Condensed, Barlow, Share Tech Mono; all OFL).
  • Snapshot the current CachyOSNordLightly + Breeze setup with konsave -s pre-visr so you can roll back in one command.
  • Make sure Plasma thinks the right 1440p screen is primary (Display Configuration → "Primary", or kscreen-doctor output.<name>.priority.1). The layout script relies on this to decide which bar gets the tray and clock.
Easy~1 evening
1QUICK WIN

Both color sets, fonts, Konsole, wallpaper

  • VisorOS.colors (front-end): slate grounds, ice accent, and a light Selection background with dark Selection foreground. That single choice gives every Qt list, menu and tab the Infinite menu look.
  • Konsole VisorOS-Backend.colorscheme: green on near-black, with the 16 ANSI colors kept readable (not everything green) so tools like btop and git diff still work.
  • An original sky/ring-arc wallpaper set, cut per monitor (2× 2560×1440, 1920×1080, 1080×1920 portrait) so the arc carries across all four screens.
Easy~1 evening
2SHELL

Plasma Style + per-screen panels

  • Fork Breeze's desktoptheme and redraw panel-background, dialogs/background, tooltip, button, lineedit, tabbar and tasks as flat slate with hairlines. Use the light-fill chip for tasks focus and tabbar selection.
  • Movable per screen: each screen gets its own independent panel, and every panel SVG gets north-/south-/east-/west- element variants. That way each bar can go on any edge (right-click → Edit Mode → Position) and still look correct, with indicators on the screen-edge side.
  • Task manager on each bar: Icons-only Task Manager with "Show only tasks from the current screen" turned on.
  • Mask elements (mask-topleft…) so KWin's blur matches each panel's shape.
Medium~1 week of evenings
3WINDOWS

Window decoration and app style

  • Aurorae decoration: flat raised-slate title bar with display-font caps, and a 2px light rule along the top of the focused window. Inactive windows drop to the Sub text color. Square buttons, with close turning red on hover.
  • Kvantum theme: flat controls, light-fill selection, segmented progress bars, square toggles. Start from KvGnome or KvAdapta as the base because they're flat already.
  • GTK apps (Firefox, Steam) pick up the colors through Breeze-GTK. Good enough to start.
Medium~1–2 weeks
4SURFACES

The custom pieces that make it one OS

  • Workspace tabs plasmoid: a pager drawn as menu tabs for the primary bar, using the org.kde.plasma.private.pager model. It stacks vertically when its bar is on a side.
  • Ammo-counter OSD: override contents/osd/Osd.qml in the Global Theme so volume, brightness and mic pop-ups show a big number plus segment "rounds".
  • Dashboard face for System Monitor: a sensor face package (arc gauges, temperature bars, segmented memory) that works both in the System Monitor app and as a desktop or panel widget.
  • Tabbed launcher (stretch goal): a full-screen QML launcher on the org.kde.plasma.private.kicker models, with Q/E tab switching and a green "run in Konsole" fallback. The cheap version is Kickoff restyled by Phase 2.
Hard~2–4 weeks
5BOOT

Back-end boot, front-end login

  • Splash: contents/splash/Splash.qml, green boot log and segmented progress, driven by Plasma's stage property.
  • Lock screen + SDDM (Qt6 greeter) share one set of front-end QML components. Test with sddm-greeter-qt6 --test-mode --theme ./sddm/VisorOS before switching to it.
  • Optional: green TTY palette via /etc/vconsole.conf and a matching Plymouth script theme. Both need root and an initramfs rebuild, so do them last.
Medium~1 week · needs sudo
6SHIP

Global Theme + layout script

  • look-and-feel/org.visoros.desktop/ with contents/defaults pointing at every layer, plus the OSD, splash and lockscreen QML.
  • contents/layouts/org.kde.plasma.desktop-layout.js loops over screenCount and creates one top panel per screen (panel.screen = i), each with a current-screen-only task manager. Screen 0 is the primary, and only its panel gets the launcher, workspace tabs, tray and clock. After that, move any bar wherever you like and Plasma remembers it per screen.
  • Apply with plasma-apply-lookandfeel -a org.visoros.desktop. Keep the art original (no Halo or 343 logos or ripped assets) if it ever goes on the KDE Store.
  • Later polish: icon overrides on top of a line icon theme, an SVG cursor theme, and a subtle sound theme.
Easy~1 evening
